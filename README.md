# 🫀 Heart Disease Prediction Project

This project aims to predict the likelihood of heart disease using machine learning models applied to a structured dataset of patient information.

## 📊 Project Overview
Using the UCI Heart Disease dataset, this notebook walks through the full data science process: data preprocessing, model training, evaluation, and interpretation.

## ⚙️ Key Features
- **Data Preprocessing:** Encoding categorical variables, scaling features, and handling missing data.
- **Modeling:** Applied Logistic Regression, Decision Tree, Random Forest, and KNN classifiers.
- **Evaluation Metrics:** Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
- **Visualization:** Used Matplotlib to explore data distribution and compare model results.
- **Interpretability:** Feature importance visualization to understand key predictors.

## 🛠 Tools & Libraries
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## 📈 Results
The Random Forest model showed the best overall performance in terms of accuracy and balance between precision and recall.

## 🚀 How to Run
1. Clone the repository.
2. Install requirements via `pip install -r requirements.txt`.
3. Run the Jupyter Notebook: `Final Project Heart Disease.ipynb`.
